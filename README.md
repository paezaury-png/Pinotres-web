# PINOTRES Constructora — sitio web

Sitio estático responsive (HTML, CSS y JavaScript), preparado para GitHub y Vercel.

## Publicar en Vercel
1. Descomprime el ZIP.
2. Sube el contenido de esta carpeta a un repositorio de GitHub.
3. En Vercel selecciona **Add New → Project** e importa ese repositorio.
4. Framework Preset: **Other**. Build Command: vacío. Output Directory: `.`.
5. Pulsa **Deploy**.

## Antes de publicar
- Confirmar que el pin del mapa corresponde exactamente a la sala de ventas de Altezza; se integró el mapa/iframe suministrado.
- Confirmar con el equipo comercial la información, disponibilidad y condiciones vigentes del proyecto.
- La sección de comentarios usa `localStorage`: los comentarios solo se guardan en el navegador del visitante. Para comentarios públicos se requiere backend, base de datos y moderación.
- El formulario de comentarios no envía datos a PINOTRES.
- Añadir Google Analytics 4 (ID de medición) y el aviso/gestión de consentimiento aplicable antes de activar analítica.
- La información de subsidios es orientativa. Actualizarla y validarla con fuentes oficiales antes de cada publicación; no se prometen montos ni asignaciones.
- Los videos proporcionados están en `assets/videos/` y se reproducen localmente.
